# Task Tracker Application

A full-stack task tracker application built with **React.js** (frontend), **Node.js/Express.js** (backend), and **MongoDB** (database). Users can create projects, add tasks under projects, update task statuses, and delete tasks.

## 📁 Project Structure

Task-Tracker/
├── client/ # React frontend
├── server/ # Express backend
└── README.md

## 🚀 Features

✅ User authentication (JWT-based)  
✅ Create, update, delete projects  
✅ Add tasks under each project  
✅ Update task status (Pending, In Progress, Completed)  
✅ Delete tasks  
✅ Responsive UI with Material UI

## 🛠️ Tech Stack

- Frontend: React.js, Axios, React Router, Material UI
- Backend: Node.js, Express.js, MongoDB, Mongoose, JWT
- Database: MongoDB
